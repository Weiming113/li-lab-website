# The Li Lab Website

Pure-frontend academic lab site for The Li Lab (Weiming Li, Ph.D.), Department of Biology, University of Texas at Arlington.

Projected live URL: https://weiming113.github.io/li-lab-website/

## Pages

- Home — index.html
- Research — research.html
- Publications — publications.html
- People — people.html
- News — news.html
- Contact — contact.html

## Tech

- Vite multi-page static HTML/CSS/JS (vanilla)
- Oswald + Open Sans fonts
- UTA blue (#0064B1) / orange (#F58025) accents
- Configured with project-site base path /li-lab-website/

## Local development

Install dependencies, start the Vite development server, then create and preview a production bundle using the scripts in package.json (dev, build, preview).

## Hosting notes

Merge to main, then in repository Settings enable Pages with a workflow source that publishes the production output folder (dist).

## Assets

Media files live in public/media/ and are copied into the build output.
